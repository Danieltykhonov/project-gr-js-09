# Booksy

Односторінковий сайт книгарні **Booksy**: каталог популярних книг з фільтрацією
за категоріями, детальна інформація про книгу, відгуки покупців, анонси подій і
контакти магазину.

**Живий сайт:** https://danieltykhonov.github.io/project-gr-js-09/

## Про проєкт

Booksy допомагає читачам швидко знайти нову книгу:

- переглянути популярні книги та відфільтрувати їх за категорією;
- відкрити картку книги з описом, ціною, вибором кількості та інформацією про
  доставку й повернення;
- почитати відгуки інших покупців;
- зареєструватися на книжкові події магазину;
- знайти адресу і контакти книгарні на карті.

Дані про книги та категорії завантажуються з
[Books API](https://books-backend-v2.b.goit.study/api-docs/).

## Технології

- HTML5, CSS3 (Mobile First, медіа-функція `min-width`)
- JavaScript (ES6+ модулі)
- [Vite](https://vitejs.dev/) — збірка проєкту, `vite-plugin-html-inject` для
  partials
- [Axios](https://axios-http.com/) — запити до API
- [Swiper](https://swiperjs.com/) — слайдери в секціях Hero, Feedbacks, Events
- [Accordion JS](https://github.com/michu2k/Accordion) — акордеон у модальному
  вікні книги
- [iziToast](https://izitoast.marcelodolza.com/) — повідомлення про помилки та
  успіх
- [AOS](https://michalsnik.github.io/aos/) — анімація появи секцій при скролі
- [modern-normalize](https://github.com/sindresorhus/modern-normalize)
- Prettier, GitHub Pages, GitHub Actions

## Структура сайту

- **Header** — логотип і навігація, мобільне бургер-меню
- **Hero** — головний банер зі слайдером і кнопкою переходу до книг
- **Books** — каталог книг з API, фільтр за категоріями, лічильник і кнопка Show
  More
- **Feedbacks** — слайдер відгуків покупців
- **Events** — слайдер майбутніх подій з реєстрацією
- **Article** — розповідь про книгарню
- **Location** — контакти та карта Google Maps
- **Footer** — логотип, навігація, форма підписки
- **Book Modal** — детальна інформація про книгу, вибір кількості, акордеон
- **Contact Modal** — форма реєстрації на подію з валідацією

## Як запустити проєкт локально

1. Встановіть [Node.js](https://nodejs.org/) LTS-версії.
2. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Danieltykhonov/project-gr-js-09.git
   cd project-gr-js-09
   ```
3. Встановіть залежності:
   ```bash
   npm install
   ```
4. Запустіть режим розробки:
   ```bash
   npm run dev
   ```
   Сайт відкриється за адресою http://localhost:5173/
5. Production-збірка:
   ```bash
   npm run build
   ```
   Готові файли з'являться в папці `dist`.

## Деплой

Сайт автоматично збирається і публікується на GitHub Pages через GitHub Actions
після кожного злиття змін у гілку `main`.
